# Tijdelijke werkbestanden

Deze map bevat gegenereerde tussenbestanden, zoals gerenderde PDF-pagina's voor visuele controle. Ze zijn geen bron van waarheid en mogen nooit zelfstandig als productspecificatie of actuele aanbieding worden aangehaald.

De duurzame conclusies en bronverwijzingen horen onder `research/`. Verwijder tijdelijke bestanden alleen wanneer hun inhoud aantoonbaar in een evidence-record is vastgelegd.
