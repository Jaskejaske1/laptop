# Wireshark Windows ARM64 — SRC-0222

## Source

https://www.wireshark.org/download.html

## What it proves

Wireshark publishes an official Windows ARM64 installer alongside x64 builds. Its Windows packages include Npcap for live packet capture. This proves a useful native ARM networking tool exists, but not that every USB capture interface, Ethernet adapter or vendor-specific driver works on ARM64.
