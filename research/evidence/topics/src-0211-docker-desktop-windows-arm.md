# Docker Desktop for Windows ARM — SRC-0211

## Source

https://docs.docker.com/desktop/setup/install/windows-install/

## What it proves

Docker offers a Windows ARM installer but labels it Early Access. It uses the WSL 2 backend and does not support Windows containers on ARM. Do not treat it as equal in maturity to the x86-64 Windows release.
