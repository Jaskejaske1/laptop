# Intel Core Ultra 7 270K Plus desktop identity — SRC-0231

## Source

https://download.intel.com/newsroom/2026/ClientComputing/Intel-core-ultra-200s-plus.pdf

## What it proves

`Core Ultra 7 270K Plus` is a Core Ultra 200S Plus desktop Arrow Lake Refresh processor, launched for desktop motherboards and tested by Intel on an ASUS Z890 desktop board. `K` is not a laptop suffix.

## Notes

Intel's test configuration lists 250W. The mobile-related name is `Core Ultra 7 270HX Plus`, which is a distinct product.
