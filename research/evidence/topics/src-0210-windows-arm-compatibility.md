# Windows 11 on ARM compatibility — SRC-0210

## Source

https://learn.microsoft.com/en-us/windows/arm/faq

## What it proves

Windows 11 on ARM supports x86 and x64 user-mode application emulation. Visual Studio and Visual Studio Code have ARM-native versions. Kernel-mode and print drivers must be native ARM64 and cannot be supplied through x86/x64 emulation.
