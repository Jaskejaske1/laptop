# Laptopmarktonderzoek — start hier

Dit repository bewaart een evidence-based Belgisch laptopmarktonderzoek. De oorspronkelijke tweelaptopstrategie is momenteel vereenvoudigd: de bestaande HP EliteBook vervult voorlopig Laptop A, zodat de actieve aankoop alleen **Laptop B** is, met een support-adjusted plafond van **EUR 4444,17**.

## Ik wil gewoon weten waar we staan

Lees [`research/current.md`](research/current.md). Daar staan in vijf minuten:

- de actuele opdracht;
- de harde eisen;
- de overgebleven kandidaten;
- waarom er nog geen definitieve winnaar is;
- wat als volgende onderzocht moet worden.

De kortste actuele conclusie: de Belgische ASUS Strix G16 RTX 5080 is de schoonste rationele kandidaat; de SCAR 5080 heeft luxere hardware maar een integratieconflict; de MSI Raider 5090 biedt 24GB VRAM en goede batterij maar heeft conflicterende exacte Belgische CPU-/paneelmetadata.

## Belangrijk

- De bestanden onder `research/` zijn de bron van waarheid; chatgeheugen is dat niet.
- `PROMPT.md` en `PROMPT_ADDENDUM.md` bewaren de oorspronkelijke opdrachtcontext, maar zijn geen actuele startdocumenten.
- `research/history/` bewaart chronologie en oude momentopnamen; gebruik die niet als huidige aanbeveling.
- `research/archive/` is een onaantastbare, geverifieerde herstelkopie van vóór de herstructurering.
- Onderzoeksagents volgen bovendien [`AGENTS.md`](AGENTS.md).
